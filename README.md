# Keling - Static HTML Tourism Website

This is the original responsive local tourism website built as a group project for our Web Development course. The project showcases a clean local narrative promoting tourism, culture, and attractions along the Gambian coast.

## Project Overview
The primary objective of this project was to master the fundamental structure and styling of web pages without relying on JavaScript or modern front-end frameworks. The core technical focus centers on leveraging **CSS Flexbox** and **CSS Grid** to achieve fully responsive layouts across various screen sizes.

## Features
* **Multi-Page Architecture:** Consists of 5 static HTML pages:
  * Home / Landing Page
  * Places / Attractions Page
  * Tour Guides Page
  * Gallery Page
  * Contact Page
* **Advanced Layouts:** Implements custom CSS Flexbox and CSS Grid structures for card layouts, navigation components, and responsive image galleries.
* **Pure HTML & CSS:** Built entirely with vanilla HTML5 and CSS3 (Zero JavaScript).
* **Responsive Design:** Fluid layouts that adapt seamlessly from mobile devices to desktop viewports using media queries.

## Tech Stack
* **Markup:** HTML5
* **Styling:** CSS3 (Flexbox, Grid, Custom Properties)
* **Assets:** Local image gallery and branding media
